## Engineering work I'm proud of

### Real-Time Collaboration & Media Systems

At Louper, I developed core real-time audio/video collaboration features using React, TypeScript, LiveKit, and WebRTC.

My work included redesigning the Room interface for multiple layouts, real-time device switching, screen sharing, noise cancellation, audio output selection, participant lobbies, host controls, audio mixing, and reconnection handling.

I was involved throughout the product lifecycle, from feature discussions and UI/UX decisions through implementation, testing, deployment, and release documentation.

### React Performance Engineering

Investigated performance bottlenecks in Louper's core Room application using React DevTools and browser profiling.

Identified unnecessary re-renders, inefficient state ownership, redundant effects, unstable props, and excessive event handling.

One of the improvements reduced CPU utilization during window resizing from approximately **95% to 8–10% on Apple M1 hardware**. Other changes substantially reduced resource consumption across older devices.

After moving into engineering leadership, I shared these findings and supported developers through additional optimization rounds.

### Redis Architecture & Concurrency

Redesigned Redis-backed Room state management, moving away from a shared monolithic key toward per-Room data structures.

Investigated stale-state concurrency issues and replaced problematic read-modify-write patterns with atomic RedisJSON operations, resolving previously observed inconsistencies in collaborative workflows.

### Engineering Leadership & Delivery

At Louper, I built and developed a **12-person engineering team**, including dedicated manual and automation QA.

Helped engineers become more independent, improved planning and engineering delivery, and increased production releases from approximately monthly to weekly or multiple times per week while maintaining production stability.

I continue to work closely with engineering architecture, code reviews, production incidents, infrastructure reliability, and developer mentoring.
